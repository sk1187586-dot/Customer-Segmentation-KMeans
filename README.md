
# Customer Segmentation using K-Means

## Project Overview
This project focuses on customer segmentation using the K-Means Clustering algorithm.

## Objective
To group customers based on their Annual Income and Spending Score.

## Algorithm
K-Means Clustering

## Number of Clusters
5 Clusters

## Visualization
Customer Segmentation Graph

## Tools Used
- Python
- Machine Learning
- K-Means Clustering
- Matplotlib

## Conclusion
This project helps businesses understand customer behaviour and develop better marketing strategies.
