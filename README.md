
# Customer Segmentation using K-Means

## Project Overview
This project uses K-Means Clustering to segment customers based on their Annual Income and Spending Score.

## Objective
To identify different customer groups and understand their spending behaviour.

## Algorithm Used
K-Means Clustering

## Visualization
Customer Segmentation Graph showing 5 clusters (0 to 4).

## Tools Used
- Python
- Machine Learning
- K-Means Clustering
- Matplotlib
